## Overview

Vaulta is an offline-first encrypted password manager. The app is designed to store vault entries locally on your device using encryption. Optional remote sync may be enabled only when the app is configured with a Supabase backend.

## Data you provide

Vaulta may store information you enter into the vault, such as account names, usernames, passwords, notes, URLs, tags, and related metadata. This information can be sensitive.

## Local storage and encryption

Vaulta encrypts vault entries locally. The app uses a master password to derive encryption material for the local vault. On Android, biometrics can unlock the vault through an Android KeyStore-protected key envelope after the user enables the feature with the master password. The master password remains the recovery path and is required to activate or re-enroll biometrics. iOS, macOS, web, and desktop releases should be documented according to their actual platform support before publication.

## Optional Supabase sync

If remote sync is enabled for your release and account/session, Vaulta may transmit encrypted vault snapshots and sync metadata to the configured Supabase project. Sync metadata may include device identifiers generated by the app, timestamps, version counters, and session/revocation records needed to operate sync.

If Supabase sync is not configured, Vaulta does not initialize Supabase sync and remains local/offline-first.

## Data not intentionally collected

Vaulta does not intentionally include advertising tracking, cross-app tracking, or analytics in this repository state. Re-check this section if SDKs or telemetry are added later.

## Backups

Android cloud backup and device-transfer extraction are disabled for Vaulta app data in this repository state to reduce the risk of sensitive vault material being copied outside the app-controlled storage model. Platform-level backups outside the app's control may still depend on user device settings and operating-system behavior.

## Security limitations

Vaulta has not had an external security audit unless a later release explicitly documents one. No password manager can guarantee absolute security. Users should choose a strong master password and keep devices updated.

## User choices

Users can choose whether to enable local biometrics where supported. If remote sync/account features are enabled in the release, document account deletion, session revocation, and data deletion steps here.
